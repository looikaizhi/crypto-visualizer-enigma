# Enigma 密码机模拟器 — 前端重设计方案

> 目标：把当前「能用但简陋」的页面，重做成一台**让人想动手把玩的虚拟 Enigma 密码机**。
> 核心思路：从「表单 + 按钮」转向「实体仪器」——用户面对的不是网页，而是一台 1940 年代的德军密码机。

---

## 1. 现状诊断

当前实现（`EnigmaSimulator.tsx` + 各 CSS）的问题：

| 问题 | 具体表现 | 后果 |
|------|---------|------|
| 无场景感 | 纯 `#1a1a1a` 背景 + 扁平卡片，像后台管理表单 | 用户没有「在操作一台机器」的代入感 |
| 配置区与机器割裂 | 转子/反射器/插线板是下拉框堆叠 | 看不出它们是机器的物理部件 |
| 信号路径完全不可视 | API 已返回 `forwardResult` / `backwardResult` / `plugResult`，前端**完全没用** | 丢掉了最有教学价值、最「酷」的部分 |
| 无反馈层次 | 灯板只是 26 个方块变色，键盘是 26 个按钮 | 敲键时没有「机械感」「通电感」 |
| 无引导 | 进入即是一堆空下拉框 + 「等待输入...」 | 新用户不知从何下手，直接流失 |
| 字体/质感廉价 | 系统默认字体、纯色块、`border-radius: 8px` | 与「精密黄铜军用仪器」气质完全不符 |

**结论**：不是缺功能，是缺「形象」与「信号可视化」。本方案聚焦这两点。

---

## 2. 设计理念

**一句话定位**：一台可以拆开看内部线路的、有黄铜质感的 Enigma I 型机。

三条原则：

1. **拟物优先（Skeuomorphism）** — 真实 Enigma 是木壳 + 胶木 + 黄铜的实体。界面材质、光影、按键手感都向实物靠拢，而不是走扁平/霓虹风。
2. **信号即主角** — 每次敲键，电流从键盘 → 插线板 → 三个转子 → 反射器 → 原路返回 → 灯板。这条路径必须**被画出来、被点亮、被动画**。这是从「简陋」到「想探索」的关键转折。
3. **渐进披露** — 首次进入给「预设 + 引导」，让用户 5 秒内能敲出第一个字母；高级配置（环位、插线板）折叠收起，按需展开。

参考形象：德意志博物馆陈列的 Enigma I、丘吉尔战时密码室、布莱切利园。关键词：**黄铜、胡桃木、胶木黑、琥珀辉光、机械精密**。

## 3. 视觉系统

### 3.1 配色（覆盖技能默认的霓虹方案）

技能初始推荐的霓虹红蓝不符合 Enigma 实物气质，改用「军用仪器」色板：

```css
:root {
  /* 外壳 / 木质 */
  --case-wood-dark:   #2A1A0E;  /* 胡桃木暗部 */
  --case-wood:        #4A2F1A;  /* 木壳主色 */
  --case-wood-light:  #6B4626;  /* 木纹高光 */

  /* 金属 / 黄铜 */
  --brass:            #B8893A;  /* 黄铜主色 */
  --brass-light:      #E8C77A;  /* 黄铜高光 */
  --brass-dark:       #7A5520;  /* 黄铜阴影 */
  --steel:            #3C3F44;  /* 钢制底板 */

  /* 胶木面板 */
  --bakelite:         #15110D;  /* 黑色胶木面板 */
  --bakelite-raised:  #221C15;  /* 凸起部件 */

  /* 灯 / 辉光（信号高亮）*/
  --lamp-off:         #2B2620;  /* 熄灭的灯 */
  --lamp-glow:        #FFD56B;  /* 琥珀辉光 */
  --lamp-core:        #FFF4D6;  /* 灯丝核心 */
  --signal-live:      #FF8A3D;  /* 电流路径橙 */

  /* 文字 */
  --ink:              #EDE3CE;  /* 蚀刻字 / 主文字（米白）*/
  --ink-muted:        #9A8B6E;  /* 次要文字 */
  --engrave-shadow:   #00000099;/* 蚀刻阴影 */

  /* 语义 */
  --danger:           #B3422E;  /* 哑光军红（重置/错误）*/
  --success:          #6E8C3A;  /* 哑光军绿 */
}
```

对比度校验：`--ink (#EDE3CE)` on `--bakelite (#15110D)` ≈ 13:1（AAA）；`--ink-muted` on 同底 ≈ 5.1:1（AA）。

### 3.2 字体

```css
@import url('https://fonts.googleapis.com/css2?family=Special+Elite&family=Oswald:wght@500;600;700&family=JetBrains+Mono:wght@400;600&display=swap');
```

| 用途 | 字体 | 理由 |
|------|------|------|
| 标题 / 机器铭牌 | **Oswald**（窄体无衬线，全大写） | 接近 Enigma 面板蚀刻铭文，工业、紧凑 |
| 键盘 / 灯板 / 转子字母 | **JetBrains Mono**（等宽） | 等宽保证 26 字母网格不抖动（`number-tabular`）|
| 说明文字 / 打字效果 | **Special Elite**（打字机体） | 强化「电报 / 战时文书」氛围；正文小范围使用 |

正文段落仍用 system-ui，保证可读性与性能；Special Elite 只用于氛围性文案（欢迎语、提示）。

### 3.3 材质与质感（关键，决定「不简陋」）

不用纯色块，统一用以下手法（纯 CSS，无图片）：

- **木壳纹理**：`repeating-linear-gradient` 叠加 `--case-wood` 多层透明度模拟木纹。
- **黄铜部件**：`linear-gradient(145deg, --brass-light, --brass, --brass-dark)` + 细 `inset` 高光描边。
- **蚀刻文字**：`color: --ink` + `text-shadow: 0 1px 0 --engrave-shadow`（凹陷感）；铭牌反过来用 `0 -1px` 做凸起。
- **胶木面板**：深色 + 极细颗粒噪点（`background-image` 用 SVG `feTurbulence` data-uri）+ 柔和 `inset` 阴影。
- **圆角**：部件 `4–6px`，按键圆形/胶囊。**禁止**当前那种通用 `8px` 卡片圆角。
- **统一阴影层级**（`elevation-consistent`）：
  ```css
  --shadow-recessed: inset 0 2px 6px #000000aa;       /* 凹槽 */
  --shadow-raised:   0 2px 0 #00000066, 0 6px 14px #0008; /* 凸起部件 */
  --shadow-lamp:     0 0 18px 4px var(--lamp-glow);    /* 灯辉光 */
  ```

## 4. 整机布局

桌面端把所有部件组织成**一台机器的俯视图**，从上到下就是真实 Enigma 的物理结构：

```
┌─────────────────────────────────────────────────┐
│  铭牌：ENIGMA  ·  Chiffriermaschine   [预设▾][❓] │  ← 顶部黄铜铭牌条
├─────────────────────────────────────────────────┤
│   ╭───────── 转子仓（掀盖）─────────╮              │
│   │  [反射器]  [转子Ⅰ][转子Ⅱ][转子Ⅲ] │ ← 可展开高级 │
│   │   显示窗：  A      A     A        │   设置抽屉  │
│   ╰─────────────────────────────────╯              │
├─────────────────────────────────────────────────┤
│         灯  板   (26 个琥珀灯，QWERTZ 排布)         │
├─────────────────────────────────────────────────┤
│         键  盘   (26 个圆形胶木键，QWERTZ)          │
├─────────────────────────────────────────────────┤
│   ▤ 插线板（机器正面，10 根可拖拽跳线）  [收起▾]    │
├─────────────────────────────────────────────────┤
│  电报纸带：  输入 ▌AAABB...   输出 ▌XKCDE...       │  ← 卷动纸带
└─────────────────────────────────────────────────┘
```

要点：

- **键盘/灯板用真实 QWERTZ 三排布局**（Enigma 是德式 QWERTZ，不是 ABC 顺序）。现状按 A–Z 排列是错的，改成：
  - 第一排：`Q W E R T Z U I O`
  - 第二排：`A S D F G H J K`
  - 第三排：`P Y X C V B N M L`
- 灯板在键盘正上方，**一一对位**，让用户直观看到「按 Q → 亮某灯」。
- 转子仓做出「掀盖」效果——默认合上显示三个窗口字母，点击「掀盖」翻开露出转子可调环。
- 移动端：垂直堆叠，转子仓 / 插线板默认折叠（`content-priority`）。

## 5. 组件级重设计

### 5.1 顶部铭牌 `MachinePlate`（新增）
- 横贯顶部的黄铜蚀刻条，刻 `ENIGMA` + 副标题 `Chiffriermaschine`。
- 右侧两个黄铜旋钮按钮：**预设方案**下拉、**帮助/引导**。
- 一个微动效：进入页面时铭牌有一束「反光」扫过（`prefers-reduced-motion` 下禁用）。

### 5.2 转子组 `RotorBank`（重做 `RotorSelector`）
真实转子是带刻字滚轮。每个转子渲染成一个**立体滚轮**：

- 显示窗只露出当前字母 + 上下各半个相邻字母（`overflow:hidden` 的滚动条带）。
- 步进时滚轮**滚动动画**（`transform: translateY`，180–250ms，`ease-out`），不是数字突变。
- 滚轮上方/下方各一个黄铜小箭头按钮微调起始位置（替代下拉框）。
- 转子型号（Ⅰ–Ⅴ）通过转子侧面的小拨片切换，或长按弹出选择。
- **环位（Ringstellung）**属于高级设置，收进「掀盖」后的抽屉，避免一上来就吓退新人（`progressive-disclosure`）。
- 进位缺口（notch）在滚轮上用一个黄铜小三角标出，下一个转子步进时该标记闪一下——把「连动进位」这件抽象的事可视化。

### 5.3 反射器 `Reflector`（重做 `ReflectorSelector`）
- 渲染成转子仓最左侧一个固定的、略小的黄铜盘（UKW-A/B/C）。
- 点击切换，盘面蚀刻当前型号；不可旋转（符合史实），视觉上明显区别于转子。

### 5.4 灯板 `LampBoard`（重做）
- 26 个灯做成**圆形磨砂玻璃灯罩**：熄灭=`--lamp-off`，点亮=`--lamp-core` 灯丝 + `--lamp-glow` 外辉光。
- 点亮动画：80ms 内骤亮（白炽灯通电感），熄灭用 ~400ms 缓退（灯丝余温，`exit-faster`/余辉感）。
- 灯下方蚀刻字母随灯亮而「被照亮」。
- QWERTZ 布局，与键盘对位。

### 5.5 键盘 `Keyboard`（重做 `KeyboardInput`）
- 26 个**圆形胶木键**，黄铜圈边，键面蚀刻白字。
- 按下：键帽下沉 `translateY(2px)` + 凹陷阴影切换，配一个轻微「咔哒」音效（可静音，默认关声音，提供开关）。
- 支持**物理键盘输入**：监听 `keydown`，按真实键位映射触发，体验大幅提升（`keyboard-nav`）。
- 当前高亮被按的键；加载/请求中禁用并降透明度（`disabled-states`、`loading-buttons`）。

### 5.6 插线板 `Plugboard`（重做 `PlugboardConfig`）★ 体验重点
- 渲染成机器正面板：26 个字母**插孔**（双孔，像真实 Steckerbrett）。
- 用 **SVG 跳线**连接两个字母：点 A 再点 B，画一根带垂坠弧度（贝塞尔曲线）的「电缆」，颜色随机取一组复古电缆色。
- 已连的孔点击可拔出；最多 10 对，超出给出提示。
- 桌面端支持拖拽连线；移动端用「点击两端」（`gesture-alternative`：始终保留点击方式）。
- 这是把「枯燥的下拉配对」变成「动手插线」的关键交互。

### 5.7 信号路径可视化 `SignalPath`（全新核心组件）★★ 最重要
利用已有但被浪费的 API 字段 `plugResult` / `forwardResult` / `backwardResult`：

- 每次敲键后，**逐段点亮**电流路径：
  `键盘 → 插线板入 → 转子Ⅲ→Ⅱ→Ⅰ → 反射器 → 转子Ⅰ→Ⅱ→Ⅲ → 插线板出 → 灯板`
- 在转子仓内画一层 SVG overlay，用 `--signal-live` 橙色描出当前字母在每个转子内部「跳线」走的那一条线。
- 用 `stroke-dasharray` + `stroke-dashoffset` 动画做出「电流流动」效果，分段串行播放（总时长 ~900ms，可在设置里调速或关闭）。
- 提供「慢放 / 单步」模式：一个教学开关，让用户一段一段看电流怎么走 —— 这是把模拟器变「可探索」的杀手锏。
- `prefers-reduced-motion` 下：不做流动动画，直接静态高亮整条路径。

### 5.8 电报纸带 `TapeDisplay`（重做输入/输出区）
- 输入、输出各做成一条**卷动的电报纸带**，等宽字体，新字符从右侧推入。
- 输出纸带按 Enigma 惯例每 5 字母分组（`number-tabular` 防抖动）。
- 空状态不再是「等待输入...」，而是纸带上一行浅色打字机体提示：`敲击键盘开始加密…`（`empty-states`）。
- 提供「复制密文」「清空纸带」黄铜小按钮。

### 5.9 引导层 `Onboarding`（新增）★
首次进入（`localStorage` 标记）：

1. 机器以「装配」动画依次落位（部件淡入 + 轻微下落，~1.2s，可跳过）。
2. 弹一张「作战手册」卡片（打字机体）：3 步图示——选转子 → 敲键 → 看灯亮。
3. 提供一个**「装载每日密钥」预设按钮**：一键填好一套合法转子/反射器/插线配置，用户可立即敲键，不必先填表。
4. 引导可随时通过顶部 `❓` 重新唤起。

这一步直接解决「点进来不知道干嘛 → 流失」。

## 6. 动效规范

| 场景 | 时长 / 曲线 | 说明 |
|------|------------|------|
| 转子步进滚动 | 200ms `ease-out` | 滚轮物理滚动 |
| 灯点亮 | 80ms 骤亮 | 白炽通电 |
| 灯熄灭 | 400ms `ease-in` 缓退 | 灯丝余辉 |
| 键帽按下 | 60ms 下沉 / 120ms 回弹 | `scale-feedback` |
| 信号路径分段 | 每段 120ms，串行 | 可关闭 / 单步 |
| 插线连接 | 250ms 弹性 | 电缆「落定」 |
| 首屏装配 | 1.2s 交错 30–50ms | `stagger-sequence`，可跳过 |

全局遵守 `prefers-reduced-motion`：关闭装配、信号流动、铭牌反光，保留必要状态切换（用纯透明度/颜色）。统一动效 token：`--ease-mech: cubic-bezier(.34,1.2,.64,1)`。

## 7. 响应式

| 断点 | 布局 |
|------|------|
| ≥1024px | 完整机器俯视图，转子仓掀盖 + 信号 overlay 全开 |
| 768–1023px | 单列，部件全宽，插线板可横向滚动 |
| <768px | 垂直堆叠；转子仓 / 插线板默认折叠；键盘缩放但键 ≥44×44px；信号路径改为「路径列表」文字步骤 |

禁止横向滚动（`horizontal-scroll`）；用 `min-h-dvh`；纸带区固定高度内部滚动，不撑页。

## 8. 可访问性

- 键盘全程可操作：物理键盘直接驱动；Tab 顺序＝视觉顺序；焦点环用黄铜色 2px outline，**不移除**。
- 每个灯/键/插孔有 `aria-label`（如「字母 Q 的键」「Q 的指示灯，当前熄灭」）。
- 信号动画进行中用 `aria-live="polite"` 播报结果：`Q 加密为 X`。
- 颜色不单独承载信息：信号路径除橙色外加流动方向；错误除红色外加图标 + 文案。
- 音效默认关闭，提供开关；不依赖声音传达任何必要信息。
- 错误信息（现 `error-message`）改为机器面板上的「故障指示」红灯 + 明确文案 + 修复指引（`error-clarity`）。

## 9. 技术实现

技术栈维持现状（React 19 + CRA + TypeScript + axios），不引入重型依赖。新增建议：

- 仅引入 `lucide-react`（SVG 图标，替代任何 emoji）。
- 信号路径、插线、转子滚轮全部用**原生 SVG + CSS**，不引动画库；如需弹簧感可选 `framer-motion`（可选，非必须）。
- 新增 `src/styles/tokens.css` 存放第 3 节所有 CSS 变量，全局引入。
- 音效用 1–2 个极小 base64 wav，`<audio>` 预加载。

### 建议文件结构

```
src/
  styles/
    tokens.css            # 颜色/阴影/动效变量
    materials.css         # 木纹/黄铜/胶木/蚀刻 mixin 类
  components/
    machine/
      MachinePlate.tsx     # 顶部铭牌（新）
      RotorBank.tsx        # 转子组（重做 RotorSelector）
      Rotor.tsx            # 单个转子滚轮（新）
      Reflector.tsx        # 反射器（重做 ReflectorSelector）
      LampBoard.tsx        # 灯板（重做）
      Keyboard.tsx         # 键盘（重做 KeyboardInput）
      Plugboard.tsx        # 插线板（重做 PlugboardConfig）
      SignalPath.tsx       # 信号路径 SVG overlay（新，核心）
      TapeDisplay.tsx      # 电报纸带（重做输入/输出区）
    onboarding/
      Onboarding.tsx       # 首次引导（新）
      PresetMenu.tsx       # 预设/每日密钥（新）
  hooks/
    usePhysicalKeyboard.ts # 物理键盘监听（新）
    useEnigmaState.ts      # 抽离 EnigmaSimulator 的状态逻辑
    useSound.ts            # 音效开关（新）
  EnigmaSimulator.tsx      # 仅做布局编排，逻辑下沉到 hook
```

### 分阶段落地

| 阶段 | 内容 | 价值 |
|------|------|------|
| **P1 视觉骨架** | tokens/materials、铭牌、木壳布局、QWERTZ 键盘+灯板、胶木/黄铜质感 | 「简陋感」立刻消失 |
| **P2 机械交互** | 转子滚轮动画、键帽手感、物理键盘、电报纸带、插线板连线 | 「想动手」 |
| **P3 探索核心** | SignalPath 信号可视化 + 慢放/单步、进位缺口标记 | 「想探索」「学到东西」 |
| **P4 首程体验** | Onboarding 装配动画、每日密钥预设、帮助手册 | 留住新用户 |
| **P5 打磨** | 音效、a11y 全面校验、响应式、reduced-motion | 交付质量 |

## 附：设计系统来源

本方案由 `ui-ux-pro-max` 技能生成基线（Pattern: Immersive/Interactive Experience；Style: Motion-Driven），并针对 Enigma 实物形象做了定制：**用「军用仪器」拟物色板替换了技能默认的霓虹红蓝**，因为霓虹风与 1940 年代黄铜机械仪器气质冲突。保留的技能建议：沉浸式交互模式、深色背景聚焦、动效传达因果、`prefers-reduced-motion` 适配、信号高亮策略。
